Windows 11 深度优化 —— LTSC 之道

这份指南把普通安装的 Windows 11，改造成像 LTSC 一样干净的极简系统：没有应用商店塞进来的捆绑垃圾，没有没完没了的打扰，只留下真正需要的东西。大白话，一步一步来。本指南本身也是开源的。

耗时：约 1 小时 难度：新手友好 适用：任意 Windows 11 电脑

最后更新：2026 年 10 月

从这里开始——选一条路

纯净重装新装机，或者反正打算重装？从第 2 节开始，一条路走完。 系统已装好——只做精简保留现在的系统。先做第 1 节（安全准备），然后直接跳到第 3 节精简。 只看清单步骤都熟了？直接跳到第 8 节最终清单，一项项打勾。

1. 先看这里——安全第一

约 5 分钟

动手改任何东西之前，先把这几件事做了。这 5 分钟，能省掉后面几个小时的麻烦。

  1. 备份文件。把重要文件拷到移动硬盘或云盘。纯净重装会清空系统盘。
  2. 创建还原点（如果是在现有系统上调优）：在开始菜单搜索「创建还原点」→点「创建」。第 3 节用精简工具之前，再建一个。
  3. 全程插着电源。笔记本在整个安装过程中都接通电源——大约 30–45 分钟。
  4. 备好你的 Windows 许可证。本指南默认你用自己拥有的许可证激活 Windows。资源区列出的激活工具仅供参考，是否使用、如何激活，由你自己负责。
本指南的唯一原则：每一步都可回滚；这里的任何操作都不会动 Windows 更新、蓝牙和网络服务。一台快但会把自己折腾坏的电脑，不叫优化。

2. 纯净重装

约 30–45 分钟

最轻的 Windows，是从一开始就轻的系统。本指南使用 Windows 11 IoT 企业版 LTSC——长期服务版：没有捆绑小游戏，没有应用商店的垃圾推送，功能更新也被压到最低。选 en-US IoT Enterprise LTSC 镜像（下载页链接见资源区）。同样的步骤也适用于普通版 Windows 11 ISO，只是在第 3 节要多精简一点。

  1. 做一个启动 U 盘（8 GB 或更大），用 ISO 写入后从 U 盘启动，把 Windows 装到系统盘。
  2. 安装过程中保持联网（Wi-Fi 或网线），让 Windows 能拉到基础硬件驱动。
  3. 跳过微软账户。在登录界面按 Shift + F10（部分笔记本是 Fn + Shift + F10）打开命令提示符，运行： 
    start ms-cxh:localonly
    然后用本地账户继续。
  4. 第一次开机后先跑一遍 Windows 更新，把提供的更新全部装上，然后重启。
  5. 用 Ninite 装软件。在一个页面里勾选需要的软件，一个安装包全搞定——没有工具栏，没有捆绑，一次到位。
  6. 装运行库。很多软件和游戏需要微软 Visual C++ 运行库和老版 DirectX 文件。资源区的一体化离线安装包一次覆盖所有版本，省得以后软件打不开再到处找。
  7. 用你的许可证密钥激活 Windows（设置 → 系统 → 激活）。原指南用的是 MAS（Microsoft Activation Scripts，HWID 方式），链接在资源区；请使用你自己拥有的许可证，激活的事由你自己负责。

3. 精简与隐私

约 20 分钟

两个工具，都只用它们的安全预设。先建还原点——这一节最需要它。

第 1 步——Chris Titus 的 winutil

以管理员身份打开 PowerShell，运行：

irm https://christitus.com/win | iex
  1. 在 Tweaks（调整）选项卡里选择 Recommended（推荐）预设——不要超出这个范围。
  2. 运行调整，然后重启。

第 2 步——O&O ShutUp10++

  1. 打开 O&O ShutUp10++，它问要不要建还原点时，让它建。
  2. 只应用推荐设置（绿色的那些）。黄色和红色的项目正是把系统弄坏的重灾区，别碰。
  3. 再重启一次。

第 3 步——卸掉你永远不会打开的东西

设置 → 应用 → 已安装的应用：把预装的小游戏、试用软件、以及明显不属于你的东西卸掉。拿不准是什么的，就留着——磁盘空间不值钱，系统坏了才贵。

更喜欢脚本？Win11 MinMax Toolkit 是本指南在 GitHub 上的配套脚本：几分钟内自动完成本节（以及第 4–5 节）里可脚本化的安全部分——先建还原点、全部可回滚，绝不动 Windows 更新和 Defender。
永远不要精简掉：Windows 更新、Windows Defender、蓝牙、打印和网络服务。号称能删这些的工具不是在让电脑变快，是在让它变脆。

4. 性能调优

约 15 分钟

电源计划——切换之前先读这一段

  • 台式机：开启卓越性能计划。打开 PowerShell 或终端，运行： 
    powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
    然后在设置 → 系统 → 电源（或控制面板 → 电源选项）里选中「卓越性能」。
  • 笔记本：老老实实待在「平衡」。笔记本开卓越性能，买来的只有发热和风扇噪音，不是速度。平衡模式在负载上来时一样会跑满。

让内存跑满速——XMP / EXPO

  1. 重启，开机时按 Del 或 F2 进入 BIOS。
  2. 开启 XMP（Intel）或 EXPO（AMD），让内存跑在标称频率，而不是慢吞吞的默认频率。
  3. 保存退出。万一之后开不了机，把这项改回 Auto——不是每块主板都能让内存条在标称参数下稳定运行。

DNS——一个小而免费的加速

把网卡的 IPv4 DNS 设成快速的公共解析服务：

Primary:   1.1.1.1   (Cloudflare)
Secondary: 8.8.8.8   (Google)

设置 → 网络和 Internet → 你的网卡 → DNS 服务器分配 → 手动。选一家做主 DNS，另一家做备用即可。

网卡驱动

去网卡或笔记本厂商官网下载最新驱动——不要用驱动精灵类的软件。装完之后，网卡的高级设置保持默认即可，除非你有明确要解决的问题；默认值本身就是调好的。

开机启动项

任务管理器 → 启动应用：把不需要一登录就运行的东西全关掉（游戏启动器、各种更新程序、你自己会打开的聊天软件）。对大多数电脑来说，这是日常使用里最大的一笔提速。

5. 浏览器

约 5 分钟

三个实验选项能让 Chrome 明显更利索。打开 chrome://flags，把下面每一项设为 Enabled（启用），然后重启浏览器：

Parallel downloading:            #enable-parallel-downloading
GPU rasterization:               #enable-gpu-rasterization
Experimental QUIC protocol:      #enable-quic

再从 Chrome 应用商店装一个 uBlock Origin——一个扩展挡掉大部分广告和跟踪器，页面加载也跟着变快。干净的浏览器只需要这些；装上十个扩展，会把这份指南的成果全部抵消。

6. 可选 / 进阶

约 10 分钟，全部可选

这一节里的每一项都是取舍，不是白捡的便宜。全跳过，指南照样成立。

内存完整性——把代价说清楚

内存完整性（内核隔离）是一项安全功能，用来阻止未签名的驱动进入内核内存。老一些的指南——包括本指南的原版——会把它关掉，换一点性能。

  • 现代硬件上，保持开启。现在的 CPU 处理它几乎零开销，而它对日常主力机是实打实的保护。
  • 关闭它属于可选进阶操作：只有在专门的游戏机或单一用途机器上，你实测它确实掉帧、且接受驱动安全性下降时，才考虑关。路径：Windows 安全中心 → 设备安全性 → 内核隔离 → 内存完整性。

CompactOS——用上一个月之后再说

系统稳定运行一段时间后（原指南是等大约一个月），Windows 可以压缩自己的系统文件，腾出几个 GB。在管理员终端运行：

compact.exe /compactos:always

最适合小容量 SSD。NVMe 够快、空间也够的话，换来的只是存储空间，不是速度——而且随时可以用 compact.exe /compactos:never 还原。

7. 千万别做

约 2 分钟读完

  • 不要运行视频简介里随手分享的「一键精简」脚本。一个连改什么都不肯明说的脚本，不是工具，是风险。
  • 不要为了「性能」禁用 Windows 更新、Defender 或防火墙。收益几乎为零，丢掉的是安全网。
  • 不要用注册表清理和驱动 booster 类软件。它们制造的问题比解决的多得多。
  • 不要在 ShutUp10++ 或 winutil 里超出推荐预设乱勾，除非你能准确说出那一项到底改了什么。
  • 不要把关安全功能（内存完整性、SmartScreen）当成默认习惯——只能是实测之后的单机决定。
  • 不要从乱七八糟的转载站下载 Windows 镜像或工具。用资源区的链接，有哈希就验哈希。
